# T19 · 只读验身 → 人工确认 → 写入 → 正常重启

> 在 T18 审计结论 `SAFE_TO_REQUEST_FLASH=YES` 的基础上，对当前 EasyInput V2.0 实板完成一次受控写入。设备身份在本记录中只保留 MAC 后四位；完整 MAC 只在当次对话中显示。端口与工具命令由使用者在本机终端执行，Agent 读取本机日志判断结果。

## 结果

| 状态 | 值 | 依据 |
|---|---|---|
| `DEVICE_CONFIRMED` | **YES** | 唯一候选端口；ESP32-S3 (QFN56) rev v0.2，内置 8MB PSRAM；MAC 后四位 `9ea0`，与此前多次验身为同一块板 |
| `FLASH_WRITTEN` | **YES** | 写入前在同一端口重验 MAC 一致；三个产物全部写入且 `Hash of data verified`；`WRITE_RC=0` |
| `NORMAL_POWER_CYCLE_CONFIRMED` | **YES** | 使用者按指引用板上开关完全关机再开机，未按 BOOT；随后未出现下载模式串口，主机识别到应用自身的 USB 设备 |
| `POST_FLASH_READY` | **YES** | 依据为 USB 枚举：主机看到固件声明的 USB HID 设备（产品名 EasyInput AI，VID 0x303a、PID 0x1006，序列号为板型字符串），没有 ROM 下载口；这是应用层运行证据，不是串口日志匹配 |
| `FUNCTION_VERIFIED` | **NO** | 未做按键、Host Action、USB／BLE 报告或 App 联调验证 |

## 过程

1. **变更门**：读取 T16—T18 记录；本机烧录副本源码树与审计一致、工作区 0 改动，无源码或配置文件新于构建产物，三个产物指纹与审计一致。未触发 `REAUDIT_REQUIRED` 或 `REBUILD_REQUIRED`。
2. **工程声明**（`esp-idf-cy`）：ESP-IDF v5.5.5，目标 esp32s3，板型 `v2`；工程版本 `course-host-action-v1-complete-v1-9-gf528f44`，固件版本字符串 `0.4.53-idf-v2-ble-store-v1`；Flash 16MB／DIO／80MHz。
3. **板级规则**（`easyinput-board-cy`）：EasyInput V2.0 ＝ 固件别名 `v2`；开机状态短按并松开一次 BOOT 进入下载模式；退出时关机再开机，不再按 BOOT；无 RESET 键。
4. **只读验身**：首次自动扫描没有候选端口（正常运行的固件不暴露串口），视为自动连接失败；按唯一允许的实体操作，保持开机、短按并松开一次 BOOT，只重试一次，得到唯一端口并以 `--before no_reset --after no_reset` 只读读取芯片与 MAC，板子停在下载模式。
5. **写入授权**：展示授权卡（端口、芯片、完整 MAC、工程版本／目标、产物、命令）；收到使用者原样输入的“确认烧录到9ea0”后才生成写入脚本。
6. **写入**：脚本先核对三个产物指纹，再在同一端口只读重验 MAC，一致后在 `build/` 目录执行项目 `flash_args`：

   `python -m esptool --chip esp32s3 -p <端口> -b 460800 --before default_reset --after hard_reset write_flash @flash_args`

   | 偏移 | 产物 | 大小 | 指纹前缀 | 校验 |
   |---|---|---|---|---|
   | 0x0 | `bootloader/bootloader.bin` | 20,832 | `eb68cf24` | Hash verified |
   | 0x8000 | `partition_table/partition-table.bin` | 3,072 | `7c541b70` | Hash verified |
   | 0x10000 | `easy_input_keyboard.bin` | 1,640,832 | `fcedc1a5` | Hash verified |

   esptool 仅在写入前擦除这三个文件各自覆盖的区域；**未执行 `erase_flash`**，未改分区、偏移或设备身份。
7. **正常重启**：提示使用者用板上开关完全关机，再不按 BOOT 正常开机。
8. **一次可见性观察**（只读取主机设备列表，不连接、不写入开发板）：

   | 项 | 结果 |
   |---|---|
   | 下载模式串口 | 无 |
   | USB HID | 已识别：EasyInput AI，VID 0x303a／PID 0x1006，USB 2.0 全速 |
   | BLE | 主机蓝牙列表中未按名称找到 → **UNKNOWN**（可能未配对或未广播，本次不排查） |
   | App | 未打开 → **UNKNOWN** |
   | 灯光／开机声音 | 使用者未报告 → **UNKNOWN** |

## 说明

- 写入的固件源码与写入前板上运行的版本相同（见 T18 第五节），因此本次写入预期不改变行为；它证明的是“完整的验身、授权、写入、恢复流程在当前产物上走通”。
- 未看到的项目只记为 UNKNOWN，没有重新烧录。
